# Santhiya R. — Video Portfolio

This folder is a ready-to-publish portfolio website.

## Included
- index.html
- assets/ (3 MP4 portfolio videos + poster images)
- Santhiya_R_Video_Editor_Resume.pdf

## Publish
Upload the entire folder to a static hosting service such as GitHub Pages, Netlify, or Vercel.
The homepage is `index.html`.

## Important
The videos are included locally so the portfolio works without external video links after deployment.
